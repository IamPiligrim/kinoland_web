# План сайта «Киноленд»

Рабочий документ. Версия от 10.08.2026. Фиксирует информационную архитектуру,
контент-модель и требования к экранам до начала вёрстки.

## 1. Что мы проектируем

СДЦ «Киноленд», Калининград, ул. Киевская 71 — три бизнеса под одной крышей:

| Направление | Точка выхода | Кто отвечает |
| --- | --- | --- |
| Кинотеатр | Афиша.ру (билеты), Пушкинская карта | Касса +7 (4012) 97-50-20 |
| Кафе «Марио» | Яндекс Еда, Купер, самовывоз | Пиццерия +7 (4012) 97-52-51 |
| Банкетный зал | Звонок / заявка, от 2500 ₽ с человека | Информация +7 (4012) 61-15-69 |

Аудитория — семьи Калининграда, не киногики. Устройство — преимущественно
телефон, часто «на ходу», часто уже находясь рядом с центром.

**Задача главной страницы:** за 10 секунд человек понимает, что идёт сегодня,
что можно заказать и где отметить праздник, и уходит в нужную внешнюю точку.
Сайт не продаёт билеты и не принимает заказы сам — он доводит до Афиши,
агрегатора доставки или телефона. Это надо признать в дизайне честно, а не
имитировать корзину.

**Три разных намерения = три двери.** Главная — не лента новостей с блоками
(как в оригинале), а развилка на три сценария с приоритетом расписания.

## 2. Что берём из оригинала и что меняем

Оригинальная структура: Новости (она же главная), Расписание, Доставка,
О нас/Контакты; акции и банкетный зал — блоками на главной.

Изменения:

- **Новости уезжают с главной.** Сейчас первое, что видит человек, — объявление
  про почту `b2b.kino@afisha.ru`. Первым должно быть расписание на сегодня.
- **Банкетный зал получает свою страницу.** Это отдельный коммерческий сценарий
  с конверсией «звонок/заявка», ему нужны вместимость, что входит, галерея.
- **Акции сливаются с новостями** в один поток с типом записи и сроком действия.
  Сейчас это два несвязанных блока с картинками-джипегами.
- **Расписание перестаёт быть таблицей** («Дата премьеры / Режиссёр / В ролях /
  Страна / Год») — на телефоне такая таблица нечитаема. Носитель — карточка
  фильма с рядом кнопок-времён.
- **Контакты отделяются от «О нас».** Четыре телефона с разным назначением —
  это функциональный блок, он нужен в подвале на каждой странице.
- **Чебуречная «ЧеПронто» закрыта** (новость на оригинале: блюда перешли в кафе
  «Марио»). Телефон 97-52-53 и категорию меню перепроверить с заказчиком.

## 3. Карта сайта

```
/                       Главная — развилка на три сценария
/schedule               Расписание сеансов (день по умолчанию — сегодня)
/movies/:slug           Карточка фильма: описание, трейлер, все его сеансы
/food                   Кафе и доставка — витрина меню + точки заказа
/banquets               Банкетный зал — предложение и заявка
/news                   Новости и акции (единый поток)
/news/:slug             Отдельная запись
/about                  О центре, контакты, как добраться, реквизиты
/privacy                Политика обработки персональных данных
/cookies                Уведомление о cookie
404                     Не найдено
```

Правила посещения остаются PDF (`/data/uploads/rules.pdf`) — ссылка в подвале.

**Навигация:** Расписание · Кафе · Банкеты · Новости · О центре.
Постоянный CTA «Купить билеты» — справа в шапке, на мобильном закреплён снизу.
Телефон кассы кликабелен (`tel:`) в шапке на мобильном.

## 4. Контент-модель

Всё содержимое — типизированные TS-модули в `src/content/`, доступ через
единственный слой `src/api/`. Это позволяет позже заменить статику на CMS или
выгрузку из Афиши, не трогая компоненты.

```ts
type AgeRating = '0+' | '6+' | '12+' | '16+' | '18+'

type Movie = {
  slug: string
  title: string
  originalTitle?: string
  ageRating: AgeRating
  genres: string[]
  country: string
  year: number
  durationMin: number
  director: string
  cast: string[]
  synopsis: string
  posterUrl: string
  backdropUrl?: string
  trailerUrl?: string
  releaseDate: string        // ISO
}

type Showtime = {
  movieSlug: string
  startsAt: string           // ISO с таймзоной Europe/Kaliningrad
  hall: string
  format: '2D' | '3D'
  priceFrom: number          // ₽
  pushkinCard: boolean
  ticketUrl: string          // прямая ссылка на сеанс в Афише
}

type MenuCategory = { slug: string; title: string; order: number }

type MenuItem = {
  categorySlug: string
  title: string
  description?: string
  weightG?: number
  price: number
  imageUrl?: string
  tags?: ('новинка' | 'детское' | 'острое' | 'вегетарианское')[]
}

type NewsPost = {
  slug: string
  type: 'news' | 'promo'
  publishedAt: string        // ISO
  validUntil?: string        // только для promo
  title: string
  excerpt: string
  body: string
  imageUrl?: string
}

type Phone = { label: string; number: string; href: string }
```

Категории меню из оригинала: Супы, Горячие блюда, Паста, Закуски, Салаты,
ЧеПронто!, Десерты, Детское меню, Попкорн, Пицца, Напитки, Подарочные
сертификаты. Цены и состав блюд на сайте отсутствуют — нужна выгрузка от
заказчика (см. открытые вопросы).

Форматирование: `Intl.DateTimeFormat('ru-RU')` для дат, 24-часовое время,
`Intl.NumberFormat('ru-RU', { style: 'currency', currency: 'RUB' })` для цен.
Все даты сеансов считаем в `Europe/Kaliningrad` (UTC+2), не в локали браузера —
иначе гость из другого часового пояса увидит сдвинутое расписание.

Первый экран занимает сегодняшнее расписание — это и есть герой страницы,
никакого отдельного слайдера-баннера. Постеры фильмов дают всю цветность,
интерфейс вокруг них остаётся тихим.

Состояние «сегодня сеансов нет» (выходной, техперерыв) — обязательный вариант
верстки, а не пустой блок: сообщение + переход на завтрашний день.

### 5.2 Расписание `/schedule`

- Лента дней сверху: «Сегодня», «Завтра», далее даты «пт 14», горизонтальный
  скролл на мобильном, выбранный день — в URL (`?date=2026-08-14`), чтобы
  ссылкой можно было поделиться.
- Список фильмов дня. Карточка: постер, название, возрастной рейтинг, жанр,
  длительность, ряд кнопок-времён.
- Кнопка времени = один сеанс: время, зал, цена от, бейдж «Пушкинская карта».
  Клик ведёт напрямую в Афишу на конкретный сеанс, `target="_blank"`,
  `rel="noopener"`.
- Прошедшие сеансы текущего дня приглушаются, но не исчезают — иначе в 21:00
  страница выглядит сломанной.
- Фильтры не нужны: в репертуаре районного кинотеатра 4–8 фильмов в день.

### 5.3 Карточка фильма `/movies/:slug`

Постер и кадр, синопсис, режиссёр/в ролях/страна/год/длительность,
трейлер (ленивая загрузка, не автоплей), все ближайшие сеансы, сгруппированные
по дням. Это же страница-приземление для ссылок из VK.

### 5.4 Кафе и доставка `/food`

Витрина, а не магазин. Сверху — три равноправных способа заказа:
Яндекс Еда, Купер, самовывоз по телефону, с честным указанием, что доставку
везёт агрегатор. Ниже — меню по категориям с якорной навигацией (липкая
полоса категорий), карточка блюда: фото, название, состав, вес, цена.
Акции («СЕНСАЦИЯ»: средние пиццы 555 ₽, большие 665 ₽) — плашка над меню
со сроком действия, а не отдельная картинка-джипег.

### 5.5 Банкетный зал `/banquets`

Вместимость, цена от 2500 ₽ с человека, что входит, галерея зала, варианты
поводов (день рождения, выпускной, корпоратив), форма заявки (имя, телефон,
дата, число гостей) с fallback на прямой звонок. Форма требует бэкенда —
до его появления кнопка ведёт на телефон и VK.

### 5.6 Новости и акции `/news`

Один поток, два типа записи. Акция несёт срок действия и визуально отличается
от новости; просроченные акции уходят в архив автоматически по `validUntil`.

### 5.7 О центре `/about`

Что за центр и что внутри, все четыре телефона с назначением, адрес, карта и
как добраться (оригинал обещает «Как нас найти?» — нужен реальный маршрут:
транспорт, парковка), часы работы, реквизиты ООО «Марио» (ИНН 3906293961),
ссылки на правовые документы.

## 6. Дизайн-направление: «Кирпич и плёнка»

Первая версия («Свет из проекционной»: тёмный уголь + анимированный
конический градиент-«луч» в углу экрана) была пересмотрена — она читалась
как типовой ИИ-дефолт для тёмных интерфейсов (тёмный фон, один тёплый акцент,
светящийся уголок с зерном). Вторая версия («Янтарь и плёнка») заменила
эффект и шрифт, но оставила саму формулу цвета — тёплый шоколадно-коричневый
фон плюс золотисто-янтарный акцент — и по заказчику эта формула сама по себе
всё ещё читалась как ИИ-дефолт: сочетание «тёмно-коричневый + золото» сейчас
настолько же затёрто в сгенерированных «премиальных» лендингах, насколько
раньше был затёрт лиловый градиент. Проблема была в цвете, а не в шрифте или
эффекте, и её было не решить точечной заменой оттенков внутри той же формулы.

Третья версия меняет саму пару цветов на две конкретные вещи одного города, а
не на абстрактную «роскошь»: обожжённый кирпич кёнигсбергской готики (тёплый
акцент, вместо золота) и балтийский штиль — холодная патина куполов и вода
залива (второй, прохладный акцент, вместо тёплой киновари). Ни кирпич, ни
патина не сводятся к формуле «тёмный фон + одинокий яркий акцент»: это два
самостоятельных цвета разной температуры, оба на равных, ни один не играет
роль «золота». Постеры фильмов остаются единственным источником произвольного
цвета, интерфейс вокруг них молчит. Кино — главный герой, кафе и банкеты
подчинены.

### Палитра

Светлая схема — билетная бумага при дневном свете — основная и живёт в
`:root`; тёмная — вечерний зал, самостоятельный вариант, а не инверсия, в
`@media (prefers-color-scheme: dark)`. Смена приоритета (было: тёмная
основная) отражает и реальный сценарий — расписание чаще смотрят на ходу,
при дневном свете, — и уход от «premium dark mode» как точки отсчёта дизайна.

| Токен | Светлая | Тёмная | Роль |
| --- | --- | --- | --- |
| `--bg` | `#F4EFE3` | `#12191A` | билетная бумага фойе / вечерний зал |
| `--surface` | `#FFFDF7` | `#1A2426` | карточки, поднятые плоскости |
| `--text-h` | `#1E2A2E` | `#F4EFE3` | заголовки, крупная типографика |
| `--text` | `#5B6A6A` | `#8FA3A0` | основной и второстепенный текст |
| `--beam` | `#A8431F` | `#E2794A` | обожжённый кирпич: CTA, время сеанса, фокус |
| `--curtain` | `#1F6E6B` | `#4FA6A0` | балтийская патина: акции, срочное, «Пушкинская карта» |

Оба нейтральных тона (`--text`, `--text-h`) — холодный грифельно-шалфейный,
без коричневого подтона обеих прежних версий: чернила и патина, а не кофе и
золото. Хардкод-хексов в компонентах нет; все контрастные пары проверены на
AA (навскидку — 4.6:1 и выше на обеих схемах).

### Типографика

Центр одновременно официальный (юрлицо, реквизиты, правила посещения) и
развлекательный (семьи, дети, праздники). Эти две задачи разведены по двум
фейсам, а не размазаны по одному компромиссному.

- **Display — Unbounded** (Google Fonts, кириллица). Геометричный гротеск,
  нарисованный под влиянием советской конструктивистской графики и
  архитектуры — что честнее для бывшего Кёнигсберга со слоями довоенной и
  советской застройки, чем округлый «дружелюбный» шрифт из каталога
  EdTech-дефолтов. Названия фильмов, заголовки разделов, цифры времени
  сеансов, крупные числа.
- **Body — Onest** (Google Fonts, кириллица). Нейтральный русский гротеск —
  держит расписание, цены, меню, реквизиты и правовые страницы в официальном
  тоне. Описания, новости, интерфейсный текст.
- **Utility — Onest** в верхнем регистре, малый кегль, трекинг +0.06em.
  Возрастные рейтинги, номера залов, подписи, эйбрау.

Конструктивистская вывеска — в заголовках, официальность — в данных и
подписях; контраст между ними и есть решение брифа. Явно отказываемся от
Inter, от округлых «мультяшных» гарнитур (Nunito и похожие) и от связки
«крупная антиква + терракота» — ни то ни другое не решение под этот бриф, а
дефолт. Unbounded уже широкий и геометричный сам по себе, поэтому вес
заголовков на ступень ниже, чем был бы под округлую гарнитуру (700/600
вместо 800/700) — геометрия несёт характер, к ней не нужен максимальный жир.
Скругления вслед за этим тоже скромнее (4px у кнопок, 10px у карточек):
острые, почти прямые углы — часть языка, а не недоработка.

Время сеанса набирается display-фейсом крупно с `font-variant-numeric:
tabular-nums`: цифры — главный носитель информации на сайте кинотеатра,
и они должны выстраиваться в столбец без дрожания.

### Сигнатура

Перфорация плёнки: тонкая строка из круглых точек, повторяющая кромку 35-мм
киноплёнки, — на нижнем крае шапки, на границах секций главной и на верхнем
крае подвала. Деталь статична (никакой анимации, включая при наведении и
загрузке) — это осознанный отказ от прежнего свечения: перфорация читается
как деталь киноаппарата в любой момент, а не как эффект, который надо
застать при появлении. `prefers-reduced-motion` не требует отдельной ветки,
потому что анимации в сигнатуре нет вообще.

Второй, куда более сдержанный акцент — кирпичная полоса в 3px над карточками
«Кафе» и «Банкетный зал» на главной, как окрашенный обрез купона у кассы.
Она не повторяется где попало: сигнатура держится на одном заметном месте
(перфорация) и одном тихом (купонная полоса), а не размазывается по всем
карточкам сайта.

### Ритм и сетка

Максимальная ширина 1280px, 12 колонок, шаг сетки 8px. Расписание дня —
горизонтальная полка карточек с прокруткой на узких экранах, а не сжатая
плитка. Крупные пустоты вокруг постеров, минимум рамок: разделяет свет и
воздух, а не бордеры.

## 7. Техническая часть

Соответствует ограничениям из `CLAUDE.md`: Vite 8 · React 19 · TS 6, строгий
`tsconfig.app.json`, без CSS-фреймворка и state-менеджера.

**Принятые решения:**

- **Маршрутизация — react-router v7.** Единственная новая зависимость.
  Вложенные маршруты под общим layout, `:slug` для фильмов и новостей,
  выбранный день расписания — в search-параметре.
- **Данные — демо-заглушка.** Правдоподобные тестовые сеансы, фильмы и меню
  в `src/content/`, доступ только через `src/api/`. Реальный источник
  (ручное редактирование, выгрузка из кассы или виджет Афиши) подключается
  позже заменой одного слоя, компоненты не трогаются.

```
src/
  api/          доступ к контенту (сейчас — статика, потом CMS/Афиша)
  content/      данные: movies.ts, showtimes.ts, menu.ts, news.ts, contacts.ts
  components/   переиспользуемое: Button, Badge, Poster, SectionHeading…
  features/     schedule/, food/, banquets/, news/
  pages/        по маршруту
  lib/          format.ts (ru-RU даты/цены), time.ts (Europe/Kaliningrad)
  styles/       tokens.css, reset.css
```

Стили: CSS Modules + дизайн-токены как CSS custom properties в `:root`
