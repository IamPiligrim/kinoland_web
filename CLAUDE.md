## Что это за проект

Редизайн сайта **https://kinoland.info** — «Киноленд», семейный развлекательный центр в Калининграде: кинотеатр + кафе + банкетный зал. Язык интерфейса — русский.

Оригинальный сайт — источник **контента и структуры**, а не визуального решения. Разделы оригинала: Новости, Расписание (сеансы), Доставка (еда), О нас/Контакты; плюс блоки акций и банкетного зала. Внешние интеграции, которые нужно сохранить как точки выхода: покупка билетов через Афиша.ру, доставка через Яндекс Еда и Купер, соцсети (VK).

Редизайн делается всерьёз, «по-дизайнерски»: не переносить старую вёрстку, а заново решать иерархию, типографику, ритм и композицию. Перед любой новой UI-задачей вызывай скилл `frontend-design` — он задаёт планку и помогает не свалиться в шаблонные дефолты (Inter + серые карточки + border-radius 8px). Ключевые экраны прототипируй как дизайнер: сначала сетка/иерархия/состояния, потом код.

## Текущее состояние кода

Репозиторий — **нетронутый стартер Vite + React**. `src/App.tsx`, `src/App.css`, `src/assets/{react.svg,vite.svg,hero.png}` и `public/icons.svg` — это демо-страница Vite, её нужно удалить/заменить, а не развивать. Реального кода проекта пока нет, поэтому архитектура ниже — это соглашения, которые надо установить с первого коммита, а не описание существующего.

Каталог не под git (`git init` не выполнялся).


## Стек и его ограничения

Vite 8 · React 19 · TypeScript 6 · ESLint 10 (flat config). Ни роутера, ни CSS-фреймворка, ни state-менеджера, ни бэкенда нет — каждая такая зависимость это осознанное решение, обсуждай с пользователем перед добавлением.

Конфиг TS (`tsconfig.app.json`) строже дефолтного и влияет на стиль кода:

- `verbatimModuleSyntax` — импорты типов только через `import type { X } from '...'`.
- `erasableSyntaxOnly` — запрещены `enum`, параметры-свойства конструктора, `namespace`; вместо enum — union-литералы или `as const`.
- `noUnusedLocals` / `noUnusedParameters` — неиспользуемое ломает сборку, а не только линт.
- `allowImportingTsExtensions` — относительные импорты модулей пишутся с расширением (`import App from './App.tsx'`, см. `src/main.tsx`).
- `types: ["vite/client"]` — типы Node недоступны в коде `src/`, только в конфигах.

Алиасы путей не настроены: импорты относительные, пока в `vite.config.ts` + `tsconfig.app.json` не добавлен `@/`.

## Соглашения по стилям

Стартер уже задаёт паттерн, который стоит сохранить и развить: **дизайн-токены как CSS custom properties в `:root`** (`src/index.css`) плюс тёмная тема через `@media (prefers-color-scheme: dark)`, переопределяющий те же переменные. Цвета, типографика и тени в компонентах берутся только из токенов — никаких хардкод-хексов в CSS компонентов.

Значения токенов в `index.css` — фиолетовая палитра Vite; их нужно заменить на палитру «Киноленда», не ломая структуру (единый набор имён переменных, светлая и тёмная тема в паре).

Иконки — SVG-спрайт `public/icons.svg`, подключается через `<svg><use href="/icons.svg#icon-id" /></svg>` с `aria-hidden="true"` для декоративных. Новые иконки добавляй в спрайт как `<symbol id="...">`, а не отдельными файлами.

## Контент и локаль

Весь пользовательский текст — на русском. Даты, расписание сеансов и цены форматируй под ru-RU (`Intl.DateTimeFormat`/`Intl.NumberFormat`), время сеансов — 24-часовое, валюта — рубли. `index.html` пока содержит `lang="en"` и заголовок `kinoland_web` — оба поля нужно обновить.
